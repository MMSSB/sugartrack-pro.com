Pro Features Included

Everything you need for perfect monitoring.

Fluid Square UI

App-like interface with draggable bottom sheets, smooth staggered transitions, and fully responsive layouts.

Clinical Exports

Generate high-quality bilingual PDF medical reports, plus full Excel (.xlsx) and JSON capabilities natively.

Data Analytics

Real-time visual charting, automated AI insights for time-in-range, and calculated variability metrics.

Custom Theming

Complete Dark, Light, and System modes with a robust custom Accent Color engine for true personalization.

Google Drive Sync

Securely backup and restore your clinical logs directly to your personal Google Drive account with zero cloud lock-in.

Offline First

All features are fully functional without an internet connection. Your data is stored locally on your device.

Version History

The evolution of SugarTrack.

v1.2.0 Pro Current Release
  • Integrated Google Drive API for secure, private cloud backups and one-click data restoration.
  • Added dynamic Google account avatars to the sidebar, settings, and mobile header.
  • Upgraded mobile header UI with stylish, tactile floating icon buttons.
  • Published official Privacy Policy to comply with strict Google Cloud security requirements.
vr1.0 Pro Current Release
  • Initial Pro release with completely responsive Square UI System.
  • Added fully bilingual Clinical PDF Exports with Arabic support.
  • Implemented Local-First data storage and offline caching.
  • Introduced dynamic Accent Colors and Dark Mode engine.
v0.9.5 Beta Internal Testing
  • Beta testing for mobile draggable bottom sheets.
  • Integrated Chart.js for real-time visual analytics.
